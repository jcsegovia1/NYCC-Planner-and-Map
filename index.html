    How this works

    No server required

    This is a static site. Drop the files into a GitHub repository, enable GitHub Pages, and it works over HTTPS with no API key or database.

    Outdoor location

    The browser Geolocation API can track your position while this page is open. The app calculates your distance to Javits and can hand off walking directions to your maps app.

    Indoor routing

    The indoor route is a small graph based on the official map’s visible connections and access notes. Pick your nearest landmark, then choose a destination.

    Important limitation

    This is a personal navigation helper, not an official NYCC app. Indoor marker positions and walking-time estimates are approximate. Follow posted signs and staff instructions.
