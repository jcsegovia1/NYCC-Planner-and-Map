    About this Friday build

    Friday-first

    This build is deliberately centered on Friday, October 9, 2026. Thursday, Saturday and Sunday programming is not mixed into your planner.

    Source links included

    Programming cards link back to NYCC or participating publisher/event pages so you can verify late changes, reservations and access rules.

    Outdoor + indoor navigation

    Browser GPS can get you to Javits. Inside, the app uses the official floor maps and a conservative routing graph, including North Javits / River Pavilion access rules.

    Local plan

    Your saved official events and personal items are stored in your browser. No login, database or API key is required.

    Schedule can change

    This is a personal helper, not the official NYCC app. Photo-op times/groups, guests, rooms and reservations can change. Epic photo-op cards use the listed start time; the planner uses a 10-minute duration only for conflict checking.

    Data snapshot

    Friday programming and discovery data in this build was assembled October 6, 2026. Dynamic NYCC directory pages are linked where their full card data is not exposed in a static crawl.
